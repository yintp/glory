# quantitative — 量化与金融分析

本模块承载两部分内容：

1. **金融分析文档**
   - `dcf-valuation-template.md` — 机构级 DCF 估值提示词模板（V2.0 专业版）
     - 适用边界：非金融实体企业（银行/保险/地产/周期股请用对应专项方法）
     - 核心模块：红绿灯数据校验 → 三情景参数设定 → 正逆向双验证估值 → 全景数据矩阵 → 定性因素 + 风险评估
     - 适用市场：A 股 / 港股 / 美股（含三市场参数对照表）
   - `cxmt-supply-chain.md` — 长鑫存储（CXMT）产业链梳理
     - 覆盖六大环节：芯片设计/股权 → 材料 → 设备 → 洁净工程 → 封装测试 → 存储模组/终端
     - 含重点公司专题（深科技封测、有研新材靶材及其竞争格局）与订单规模排序

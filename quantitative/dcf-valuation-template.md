# 机构级 DCF 估值提示词模板（V2.0 专业版）

> **版本说明**：本模板专为资深金融分析师（CFA）设计，融合了"四大"审计式数据校验、三情景压力测试、市场隐含预期反推等专业模块。适用于 A 股 / 港股 / 美股任意标的的深度现金流折现（DCF）估值。

> **⚠️ 适用边界（前置声明）**：
> - 本模板适用于**现金流为正、资本结构稳定**的非金融实体企业；
> - **银行/保险/券商**：不适用 DCF，建议改用 **DDM** 或 **内含价值法（EV）**；
> - **房地产**：建议改用 **NAV（净资产价值）法**；
> - **强周期股**（钢铁/煤炭/航运/化工）：须先做**周期 Normalize**（取一个完整周期的平均盈利）再代入本模板，否则单一年份 FCF 会严重失真；
> - **初创/亏损企业**：FCF 为负时 DCF 失效，建议改用 **P/S、EV/收入**等相对估值法。

## 🔴 第一步：数据校验与财务"验伪"（红绿灯机制）

> **⚠️ 最高优先级规则**：本步骤若触发 🔴 **红灯**，**必须立即终止分析**，严禁进入后续估值环节！

### 1.1 多源数据交叉核对

必须从 **至少三个独立数据源**（如 Wind、东方财富 Choice、公司财报原文）获取以下核心数据（近 3 年 + 最新季报）：

- 营业收入
- 归母净利润
- 经营活动现金流净额
- 资本开支（购建固定资产、无形资产支付的现金）
- 有息负债（短期借款 + 长期借款 + 应付债券）
- 货币资金

### 1.2 三色信号灯校验规则

请以下表格式输出校验结论：

| 校验维度 | 🟢 绿灯（通过） | 🟡 黄灯（警告/调整） | 🔴 红灯（终止） |
| :--- | :--- | :--- | :--- |
| **数据一致性** | 三方来源数据完全一致 | 存在微小差异（< 2%），可取中值或年报为准 | 存在重大差异（> 5%），且无法溯源 |
| **利润含金量** | 经营现金流 / 净利润 > 0.8 | 经营现金流 / 净利润 在 0.5~0.8 之间，需分析应收/存货变动 | 经营现金流与净利润方向背离（一正一负），或比值 < 0.3 |
| **盈利稳定性** | 营收/净利润同比波动 < ±15% | 波动在 ±15%~±30% 之间，且财报附注给出合理解释 | 波动超过 ±30%，且存在"会计差错更正"、"重大会计重述"或"非标审计意见" |
| **资产负债表安全** | 货币资金 > 有息负债，净现金为正 | 货币资金略低于有息负债，但流动比率 > 2 | 存在"存贷双高"嫌疑（货币资金和有息负债同时占总资产比例异常高） |

### 1.3 异常处理机制

- **若触发 🟡 黄灯**：**不得直接采用当期数据**，必须采用"过去 5 年平均值"或"正常化盈利"（剔除一次性损益）进行调整，并在报告中明确说明调整逻辑。
- **若触发 🔴 红灯**：**立即停止分析**，输出一份《财务数据异常校验报告》，列明具体疑点、数据来源对比、以及建议的进一步尽调方向，**绝不强行估值**。

## ⚙️ 第二步：核心参数设定（三情景压力测试）

> **注**：所有参数必须基于第一步确认的"**正常化基准自由现金流**"进行调整，而非直接采用异常年份的极端数据。

### 2.1 基准自由现金流（FCF）

**计算公式**：
> **FCF（FCFF）= 经营活动现金流净额 + 税后利息 − 资本开支**（购建固定资产、无形资产支付的现金）

> **口径说明**：
> - 严格 FCFF 应加回税后利息（利息费用 × (1 - 所得税率)），因为 CFO 已扣除利息支付，而 FCFF 是全资本（含债权）口径；
> - 对**低杠杆企业**（有息负债/总资产 < 10%），可近似用 `FCF ≈ CFO − CapEx`，但须在报告中注明近似口径；
> - 上述"资本开支"为**维持性 + 扩张性**合计（报表口径），如需区分，须从财报附注拆分 maintenance vs growth CapEx。

需在报告中清晰列出：
- 所选基准年份（通常为最近完整财年或 TTM）；
- 调整项目说明（剔除诉讼赔偿、政府补助、资产处置、公允价值变动、重组费用等**非经常性损益**，还原正常化现金流）。

### 2.2 未来 FCF 增速（两阶段模型）

| 阶段 | 时间跨度 | 设定逻辑 |
| :--- | :--- | :--- |
| **第一阶段（增长/恢复期）** | 前 5 年（如 2026-2030） | 结合至少 3 家头部券商的一致预期，以及行业渗透率/天花板，进行 **悲观 / 正常 / 乐观** 三情景设定。 |
| **第二阶段（成熟过渡期）** | 后 5 年（如 2031-2035） | 增速从第一阶段末尾线性下滑至永续增长率，体现企业从成长股向价值股的切换。 |

> **三情景量化锚定**（防止情景设定随意化）：
> - **悲观情景**：前 5 年增速 ≈ 正常情景的 **60%~70%**，WACC 上浮 1%~1.5%，g 取 1.5%~2.0%；
> - **正常情景**：取券商一致预期中位数，WACC 按本节计算，g 取 2.5%~3.0%；
> - **乐观情景**：前 5 年增速 ≈ 正常情景的 **120%~130%**，WACC 下浮 0.5%~1%，g 取 3.0%~3.5%。
> 三情景的 WACC 与 g 须同步调整以保持内部一致性。

### 2.3 折现率（WACC）

**必须拆解计算过程**，不可直接给一个模糊数字：

- **无风险利率（Rf）** = 当前 10 年期国债收益率（如中国/美国，视上市地而定）；
- **β 系数** = 参考公司过去 5 年相对于大盘指数的波动率（可参考 Wind/Bloomberg）；
- **市场风险溢价（MRP）** = 一般取 6%~7%（A 股长期中枢）；
- **股权成本（Re）** = Rf + β × MRP；
- **债务成本（Rd）** = 税前利息率（如借款综合利率，不扣税）；
- **WACC** = (E/V) × Re + (D/V) × Rd × (1 - 所得税率)；
- **权重 E/V、D/V** 必须采用**市场价值**而非账面价值。

> **⚠️ 避坑**：Rd 必须使用**税前**利息率，税盾效应由 WACC 公式中的 `(1 - 所得税率)` 体现，**切勿**对 Rd 先扣税再代入公式，否则会重复扣税、系统性低估 WACC。

**三市场参数对照表**：

| 参数 | A 股 | 港股 | 美股 |
| :--- | :--- | :--- | :--- |
| 无风险利率 Rf | 中国 10 年期国债收益率 | 美国 10 年期国债收益率（港股多用美债基准） | 美国 10 年期国债收益率 |
| 市场风险溢价 MRP | 6%~7% | 6%~7%（关注港股流动性折价） | 5%~6% |
| β 系数基准指数 | 沪深 300 | 恒生指数 或 MSCI China | 标普 500 |
| 所得税率 | 25%（高新 15%） | 16.5%（香港利得税） | 21% 联邦 + 州税 |
| 股息税影响 | 红利税差异化 | H 股股息预扣税 10%（内地股东 20%） | 非居民股东 30% 或协定税率 |
| 报告货币口径 | 人民币 | 港币（关注人民币资产 End-OfDay 换算） | 美元 |

### 2.4 永续增长率（g）

- **硬性约束**：g **不得高于** 长期 GDP 增速（中国 2035 年前目标约为 4%~4.5%）的 **70%~80%**；
- **合理区间**：严格限制在 **1.5% ~ 3.5%** 之间，防止终值（TV）虚高，扭曲估值结果。

## 🧮 第三步：估值逻辑推导（正向 + 逆向双验证）

### 3.1 正向推导（绝对估值法）

1. 逐年计算未来 10 年的自由现金流（FCF₁ ~ FCF₁₀）；
2. 计算 **终值（TV）**：
   > **TV₁₀ = FCF₁₀ × (1 + g) / (WACC - g)**
3. 将所有现金流折现至今日：
   > **PVCF = Σ (FCFₜ / (1 + WACC)ᵗ)**
   > **PVTV = TV₁₀ / (1 + WACC)¹⁰**
4. 最终：
   > **企业价值（EV）= PVCF + PVTV**
   > **总股权价值 = EV − 有息负债 + 货币资金**（即扣减净债务；若存在少数股东权益、优先股，需一并调整）
   > **每股内在价值 = 总股权价值 / 总股本**

> **⚠️ 口径声明**：本模板的 FCF 指**企业自由现金流（FCFF）**，折现得到的是**企业价值（EV）**，必须经上述桥接才得到**股权价值（Equity）**。严禁跳过净债务扣减直接将 EV 当作股权价值。

### 3.2 逆向推导（市场隐含预期）

> **这是专业报告的画龙点睛之笔！**

利用 **当前企业价值（EV₀）** ，反向求解使得以下等式成立的 **隐含折现率（IRR）**：

> **EV₀ = 当前市值 + 有息负债 − 货币资金**
> **EV₀ = Σ (FCFₜ / (1 + IRR)ᵗ) + [TV₁₀ / (1 + IRR)¹⁰]**

> **口径一致性**：等式两侧均为**企业价值（EV）口径**——左侧 EV₀ 由市值加回净债务得到，右侧为 FCFF 折现值。由此反推出的 IRR 即**市场隐含 WACC**，可直接与第二步计算的 WACC 对比，判断市场情绪：

- 若 **隐含 IRR 远高于 WACC**（如 > 10%），说明市场极度恐慌，股价被严重低估；
- 若 **隐含 IRR 接近或低于 WACC**，说明市场定价较为理性或偏乐观；
- 若 **隐含 IRR 低于 WACC** 较多，说明股价存在泡沫。

## 🔍 第四点五步：定性因素分析（不可跳过）

> DCF 给出的是"数字精确度"，定性因素决定的是"方向正确性"。机构级报告**严禁只给数字不给定性**——治理风险恰恰是红绿灯想防的盲区。

### 4.5.1 行业竞争格局（波特五力）
- **现有竞争者强度**：行业 CR3/CR5 集中度、价格战/份额战迹象；
- **新进入者威胁**：资本壁垒、技术壁垒、牌照壁垒；
- **替代品威胁**：技术路线迭代风险（如电动车对燃油车的替代）；
- **上游议价能力**：原材料集中度、是否存在战略客户依赖；
- **下游议价能力**：客户集中度、是否存在"大客户依赖"披露。

### 4.5.2 管理层质量
- **核心管理层履历**：是否行业老兵、过往战略执行力（指引 vs 实际兑现率）；
- **关联交易**：与控股股东/实控人旗下企业的关联交易占比；
- **高管增减持**：过去 12 个月内部人交易方向（净增持/净减持）；
- **股权激励**：行权条件是否合理（vs 拼命式对赌）。

### 4.5.3 股权结构与治理
- **控股股东持股比例**：是否一股独大或过度分散；
- **股权质押率**：实控人累计质押比例（> 70% 视为高风险）；
- **公司治理事件**：是否曾被交易所问询、证监会处罚、出具非标审计意见；
- **ESG / 监管风险**：环保、数据安全、反垄断、行业监管政策走向。

### 4.5.4 与估值假设的勾稽
- 明确上述定性因素如何影响第二步的增速假设 / WACC / 永续 g；例如："管理层过去 3 年指引兑现率仅 60%，故悲观情景增速下调 2 个百分点"。
